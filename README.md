# Dogfight

İki telefonda Chrome üzerinden oynanan basit uçak dövüşü oyunu.

Oyna: https://sirkurtai.github.io/dogfight/

1. Bir telefonda **Oda Kur**a bas.
2. **Linki Paylaş** ile linki arkadaşına gönder (ya da 5 haneli oda kodunu söyle).
3. Arkadaşın linke tıklayınca oyun başlar.

Bağlantı eşleştirmesi için PeerJS ücretsiz sunucusu kullanılır; oyun verisi telefonlar arasında doğrudan (WebRTC) akar.
